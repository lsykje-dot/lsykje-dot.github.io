# 나의 일기장 (diary-app)

로컬 전용 안드로이드 다이어리 앱. `../DESIGN.md`(있다면) 및 대화 중 전달된
"일기장 앱 기획·설계 문서"와 디자인 캔버스에서 확정한 내용을 기준으로 작성된
1단계(MVP) 구현입니다.

## 지금까지 구현된 것 (1단계 범위)

- 잠금 화면: 지문/얼굴 생체인증 + 숫자 PIN(4~6자리) + 패턴(9점 연결), 3가지 중
  1개 이상 등록. PIN·패턴은 SHA-256+salt 해시로 EncryptedSharedPreferences(Android
  Keystore 연동)에 저장하며 원문을 저장하지 않음
- 달력 홈 화면: 월 이동, 일기 있는 날짜 점 표시, 오늘 강조, 최근 일기 목록
- 일기 작성/수정/상세 화면: 제목·본문·사진(여러 장) 저장
- 사진 첨부: 시스템 포토 피커로 선택 → 가로·세로 최대 2000px + JPEG 품질 85%로
  리사이즈·압축해 앱 내부 저장소(`filesDir/photos`)에 복사 저장. 원본 사진은
  건드리지 않음
- 로컬 Room(SQLite) DB 1개, 인터넷 권한 없음(완전 오프라인)
- 음성으로 일기 쓰기: 마이크 버튼 → 온디바이스(기기 내) 음성 인식만 사용해 텍스트로 변환 후 본문에 삽입.
  안드로이드 12(API 31) 이상 + 온디바이스 인식 모델이 설치된 기기에서만 버튼이 나타나며,
  지원하지 않는 기기에서는 버튼 자체가 보이지 않음(온라인 방식으로 대체하지 않아 로컬 전용 원칙 유지)
- PDF 내보내기: 하루 단위(일기 상세 화면) / 기간 단위(설정 → PDF 내보내기, 날짜 범위 선택)
  둘 다 지원. Android 표준 PdfDocument로 생성해 앱 캐시 폴더에 저장한 뒤 공유 시트(카카오톡·이메일·
  파일로 저장 등)로 바로 넘김. 날짜 줄 → 굵은 제목 줄 → 본문 순서로 그려서, 나중에 만들 "PDF
  불러오기"가 우리 앱 PDF를 자동으로 다시 인식할 수 있게 형식을 맞춰둠
- PDF 불러오기: 설정 → PDF 불러오기에서 파일 선택. PdfBox-Android로 글자를 추출한 뒤
  "날짜 줄 → 제목 줄 → 본문" 규칙으로 자동 인식함
  - 우리 앱이 만든 PDF, "나의일상" 앱 PDF: 날짜·제목·본문이 자동으로 채워짐(그대로
    가져오기만 누르면 됨)
  - 그 외 처음 보는 형식: 날짜를 못 찾은 부분은 통째로 한 항목에 담겨 나오고, 사용자가
    검토 화면에서 날짜를 지정하고 제목/본문을 나눠 쓴 뒤 가져옴
  - 항목별로 제목·본문 수정, 가져올지 여부(체크박스) 선택 가능. 이미 그 날짜에 일기가
    있으면 "덮어써요" 안내가 뜸(요청하신 대로 덮어쓰기 지원)
  - 사진은 이번 범위에서는 제외 — 텍스트(날짜·제목·본문)만 불러옴
- 백업 / 복원(zip): 설정 → 백업 / 복원
  - **내보내기**: 일기 DB + 사진 전체를 zip 하나로 만들어 공유 시트로 넘김(USB·SD카드·
    개인 클라우드 등 원하는 곳에 직접 옮겨두면 기기를 바꿔도 복원 가능)
  - **불러오기**: zip 파일 선택 후 "덮어쓰기"(지금 데이터를 백업 내용으로 통째로 교체) /
    "합치기"(지금 데이터는 그대로 두고, 없는 날짜만 백업에서 채워 넣음) 선택
  - 덮어쓰기는 실행 후 잠금 화면부터 앱을 다시 시작함(DB 연결 자체를 새로 열어야 해서)

## 남은 것

설계 문서 1~5단계는 모두 구현했습니다. 남은 건 실제 기기/에뮬레이터에서의 빌드·동작
검증(아래 "빌드 방법" 참고)과, 사용해보면서 나오는 다듬기 작업입니다. PDF 불러오기의
사진 복원처럼 이번에 의도적으로 뺀 부분은 위 목록에 적어뒀습니다.

## 빌드 방법 (Android Studio)

이 코드는 개발 샌드박스(안드로이드 SDK 없음)에서 작성되어 **실제 컴파일 확인은
하지 못했습니다.** Android Studio에서 열어 아래 순서로 확인해주세요.

1. Android Studio로 `diary-app` 폴더를 엽니다 (`File > Open`).
2. Gradle Sync가 자동으로 실행됩니다(처음엔 Gradle 8.7 + Android SDK 34 다운로드로
   몇 분 걸릴 수 있음).
3. 에뮬레이터 또는 실기기(API 26 이상)에서 실행합니다.
4. 지문이 등록되지 않은 에뮬레이터라면 잠금 설정 화면에서 PIN이나 패턴으로 먼저
   등록해야 앱에 들어갈 수 있습니다.

문법·구조는 꼼꼼히 검토했지만, 실제 빌드에서 버전 충돌이나 오타가 발견될 수
있습니다 — 발견되면 알려주시면 바로 고치겠습니다.

## 구조

```
app/src/main/java/com/lsykje/diary/
  data/     Room 엔티티·DAO·DB, 사진 리사이즈(PhotoStorage), Repository
  auth/     지문(BiometricAuthenticator), PIN·패턴 해시 저장(LockPrefs)
  voice/    온디바이스 음성 인식(VoiceInputRecognizer)
  pdf/      PDF 내보내기(PdfExporter)·불러오기(PdfDiaryParser, PdfTextExtractor)·공유(PdfSharer)
  backup/   백업 zip 내보내기/복원(BackupManager, BackupSharer)
  ui/theme/ 색상·타이포그래피·둥글기(디자인 캔버스와 동일한 값), 공용 버튼/칩
  ui/lock/  잠금·잠금설정 화면
  ui/calendar/ 달력 홈 화면
  ui/diary/ 일기 작성/상세 화면(음성 입력 버튼 포함)
  ui/settings/ 설정, PDF 내보내기/불러오기, 백업/복원, 준비 중 화면
  ui/nav/   화면 이동 경로 정의
```
